# 远程文件管理

在「设置 → 连接」的服务器菜单选择「浏览远程文件」，或在已选服务器的任务中打开「工作区文件」。无需发送消息或创建会话。首次使用沿用服务器已有的主机指纹确认和密码/私钥配置。

文件树和编辑器沿用本机工作面板。顶部路径栏支持登录目录、上级目录和完整路径导航；加号菜单提供新建文件/目录、上传文件/目录和隐藏文件开关。文件树右键或文件工具栏提供下载、重命名/移动、解压和删除。浏览路径不会更改 Agent 的工作目录。文件、目录和代码选区可以添加到对话，引用包含服务器身份和远端路径。

## 行为与限制

- 文本使用现有代码编辑器，支持 JSON 格式化和选区引用。完整 UTF-8 文件不超过 2 MiB 时可编辑；更大的文件只显示有界预览。保存校验 SHA-256 版本，并通过 OpenSSH `posix-rename` 扩展原子替换。冲突或不支持该扩展时保留编辑器修改，不先删除原文件。SFTP 本身没有条件写入事务，外部写入与最终替换之间仍有很小的竞争窗口。
- 图片、PDF、DOCX、XLSX、PPTX 使用现有预览器，单文件上限 12 MiB；Office 预览能力和格式限制与本机一致。
- 上传和下载使用流与临时路径，界面显示阶段、字节数和取消入口。最多同时运行 4 个文件任务；目录不超过 10000 项。不跟随符号链接或传输特殊文件。上传不覆盖已有同名目标；目录下载不合并已有本地目录；文件下载通过原生保存对话框选择位置。
- 多文件上传按文件发布，后续文件失败或取消不会撤销已完成的文件。未完成的临时内容会尝试清理；服务器断线或撤销权限可能阻止远端清理。
- ZIP、TAR、TAR.GZ、TGZ 先下载到本机临时目录校验和解压，再上传到指定的新目录，兼容仅开放 SFTP 的服务器。不覆盖已有目录；拒绝路径穿越、重复路径、链接和特殊文件。压缩包上限 256 MiB，展开内容上限 512 MiB、10000 项。异常和取消不发布解压结果。
- 删除需要确认。目录递归删除不跟随链接，服务器根目录和登录目录不能删除。取消只停止后续删除，已删除内容无法恢复。
- 任务状态保存在当前 Electron 进程中，切换面板继续传输；退出应用取消任务，重启不自动续传。

## 实现边界与验证

Renderer → LING Remote → Host IPC → Electron 主进程中的原生 `ssh2` SFTP。凭证留在主进程安全存储中，每次连接验证已有主机指纹；文件连接与 DSH Helper/PTY 生命周期独立，不安装远端 Helper、不运行远端解压命令、不改变上游 DSH。当前要求在 LING 中配置显式账号及密码/私钥；只有系统 SSH 别名的连接需先完成此配置。

`desktop/tests/sftp-files.spec.ts` 使用临时目录和拒绝 shell/exec 的隔离 SSH 服务，验证真实 SFTP 读写、目录传输、取消清理、冲突、压缩包校验；编辑替换通过文件系统测试适配器验证原子替换和权限。`tests/server-file-browser.spec.tsx` 验证无会话浏览、菜单与弹窗、冲突保留、选区引用和过期导航结果；桥接测试验证 IPC 结果校验和取消。全仓检查使用 `corepack pnpm check`。
