# 服务器运维插件

桌面本地工作区在聊天输入框工具栏显示「关联服务器」按钮，弹层按权限菜单的样式直接列出服务器并随列表高度伸缩。只有一台服务器时只占一行。Agent 也可通过 `open_server_picker` 打开聊天内的卡片。两处共用同一个 MCP App，弹层打开时聊天中保留工具记录，关闭后恢复卡片。勾选或取消服务器立即保存到当前会话，按钮显示已关联数量。没有已保存的 SSH 连接时提示前往「设置 → 远程连接」添加。草稿会话就绪后即可使用，发送首条消息沿用该会话 ID。

Window Host 持有会话关联，通过「远程设备」管理 SSH 线路和认证。选择器只接收连接 ID 和显示名，勾选即保存关联。

Agent 使用 `server_list`、`remote_run`、`server_copy`。工具经现有 MCP 审批，宿主检查当前会话关联，再复用所选线路已认证的 SSH 连接。线路离线时由用户在「设置 → 远程设备」连接。取消只关闭当前操作使用的 SSH 通道；断线后不自动重放。文件从工作区上传到远端目标目录中的临时文件，再发布到指定路径。远程开发继续使用 ZCode 的远程工作区。

MCP 服务通过仅随本机 Agent 启动注入的凭据调用 Window Host 的本地运维桥。远程工作区不持有本地连接凭据。绑定按会话 ID 保存，草稿关闭不会转移关联到另一份草稿。
