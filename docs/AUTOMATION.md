# 本地自动化

自动化是 LING 的独立主页面。它复用 DSH 的 Session Controller、模型路由、Agent 队列、沙箱与审批策略；DSH 的会话定时提醒继续保留其原始语义。没有云端服务、账号体系、订阅或独立后台守护进程，也不修改上游源码。

## 使用与执行

- 支持创建、编辑、暂停、删除、立即运行；四个模板只预填草稿。
- 支持每天、每周指定日期、固定间隔（至少 5 分钟）和仅一次；日历计划使用 IANA 时区，可指定到期时间。夏令时缺失时刻跳过，重叠时刻只执行一次。
- 默认每次新建独立任务，也可合并到这个计划的专用任务。保存计划不创建空会话，不会复用用户现有的聊天。更换工作区会重置专用任务，原执行记录仍保留。
- 模型可固定，或跟随应用默认值；实际执行采用的默认模型会保存进本次记录。
- 默认只读并保留审批。工作区写入和无需审批的完全访问是明确的计划选项；记录使用实际的 DSH `sandbox/mode` 与 `approval/policy` 事件，审批继续在原任务内处理。
- 自然语言生成只调用现有模型获取结构化草稿，不运行工具、不保存计划。模型返回的权限和工作区字段不被采纳，用户在编辑窗口选择。
- 执行记录区分排队、运行、等待审批、完成、失败、中断、取消和重叠跳过。完成由对应请求进入的回合结束事件确认。可打开原任务、取消活动执行，或按当前计划重试未完成执行。重试另建记录，不覆盖之前的结果。

## 生命周期与本地数据

计划和历史存放于当前 profile 的 `DSH_HOME/ling-automation.sqlite`（SQLite WAL、文件权限 0600），按 profile 隔离。删除计划是归档，历史不被删掉；聊天原文仍由 DSH 自己持久化。

Host 每 5 秒检查调度，不依赖自动化页面是否打开。应用必须保持运行；关闭窗口但进程仍在运行时仍可调度，退出应用后不会执行。保持唤醒使用 Electron `prevent-app-suspension`，只在有有效计划或未结束执行且开关启用时持有；Host 退出和应用退出都会释放。不会阻止用户手动退出应用。

错过计划默认跳过；可选择只补最近一次，避免恢复后产生大量任务。上一执行未结束时跳过新的定时触发，不并发运行同一计划。手动运行不改变下一计划时间。

每次执行在提交消息前持久化任务 id、请求 id 和计划快照，计划时间有唯一键。重启后首先检查 DSH 的持久化消息、收件箱与回合记录：未提交的执行沿用原请求身份；已排队输入恢复原 Agent；已进入但未完成的回合记录为中断，不主动重放工具。传输异常不会被当作成功，也不会盲目创建新的重试。外部工具的副作用不承诺 exactly-once，用户重试前可查看原任务。

当前执行位置是本机 Host，使用已注册的本地工作区与现有工具。未增加远端调度服务或假装应用退出后仍可运行。

## 验证

`corepack pnpm check` 包含纯日历计算、SQLite 重启与幂等、重叠/暂停/到期策略、DSH Session 接线与实际策略事件、执行状态、草稿隔离和 UI 边界测试。所有检查可以无图形界面运行。
