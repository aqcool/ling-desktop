# Windows XP — LING 内置主题包

版本：1.1.1 · 标识：`windows-xp`

此目录包含 XP 主题的完整源文件，可整体复制或归档。应用继续使用已有的外观设置和 `ling.palette` 偏好。

1.1 按 [第二版设计稿](../../../../docs/design/windows-xp-theme-v2.png) 调整：浅蓝资源管理器侧栏、Luna 顶栏、象牙白信息面板、白色输入面与暖灰工具栏。新会话壁纸加轻微冷色覆盖层，上下文栏透明并使用白字；输入区使用单层细边框和实线浅分隔。浅色与深色分别定义材质颜色，不改布局或交互。

1.1.1 修正整窗层级：左侧顶部导航继承侧栏背景与文字颜色，和任务列表、底部工具形成完整导航栏。Luna 标题栏只用于右侧工作区，不再把左侧顶部画成独立标题栏。

- `theme.ts`：包描述（标识、名称、版本、样式入口）、浅色/深色配色、操作按钮和阴影变量。
- `styles.css`：Luna 控件、标题栏、菜单、选中态、壁纸、图标映射；所有规则限定在 `data-palette="windows-xp"`。
- `assets/windows-xp-sky.webp`：本地 Bliss 壁纸，仅用于新会话背景。
- `assets/icons/`：LING 绘制的彩色 SVG 图标，复用原有图标尺寸；自定义工作区图标颜色优先。
- `ATTRIBUTION.md`：素材来源和使用说明。

## 维护

修改本目录中的配色、样式或素材即可。不要在业务组件中增加 XP 分支，不要改布局尺寸、拖动区域或窗口逻辑。深色是 LING 的适配方案；正文和代码保持原有阅读字体。高对比度模式回退到原生线框图标。

应用通过 `../index.ts` 注册包描述，通过 `../index.css` 导入样式。配色继续由公共生成器输出，Renderer、Host、终端和凭据窗口共享同一份定义。图片由现有 Vite 构建内联，不需要额外服务或网络请求。

```sh
corepack pnpm check:renderer
```

这是随应用构建的源码主题包。压缩包可用于备份和源码集成；当前未实现运行时 ZIP 安装或第三方主题商店。
