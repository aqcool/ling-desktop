# XP theme artwork

- `assets/windows-xp-sky.webp`: Bliss photograph by Charles O’Rear, Microsoft. Wallpaper source: https://www.wallpaperhub.app/wallpapers/6852 (original download: https://cdn.wallpaperhub.app/cloudcache/6/9/0/e/e/f/690eefe3ba1f553e0ea527f51ee407b604b681b4.jpg). Resized to 1920 pixels wide and encoded as WebP for the new-session background. The source offers images for wallpaper use; this photo is not covered by the repository’s MIT license.
- `assets/icons/*.svg`: original LING artwork for the XP theme, drawn on the existing 24-unit icon grid. No Microsoft icon assets or Windows logo are included.

The renderer embeds these assets at build time, so themes do not require network access.
